# Automatic Git Commit and Push

Whenever any changes, fixes, or additions are made to the codebase:
1. Automatically stage all modified and added files (`git add .`).
2. Commit with a clear, concise descriptive message.
3. Automatically push to the remote repository (`git push origin <branch>`).
4. Never prompt the user for confirmation or permission before staging, committing, or pushing changes.
